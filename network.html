Мониторинг сетевой активности (Network)

Панель Network

Панель Network записывает все сетевые запросы, отправляемые и получаемые страницей: HTML, CSS, JS, изображения, а также асинхронные запросы XHR/Fetch.

Важнейшие настройки панели Network
  • Disable Cache: Отключение кэширования при открытых DevTools для проверки загрузки с сервера.
  • Throttling (Ограничение скорости): Эмуляция соединения 3G/Slow 3G для проверки мобильной оптимизации.
  • Waterfall (Водопад): Диаграмма этапов загрузки (DNS lookup, Initial connection, TTFB, Content Download).

Анализ статусов ответов HTTP

Панель подсвечивает ответы цветом: 200 (ОК — зеленый), 304 (Not Modified), 404 (Not Found — красный), 500 (Server Error).

Экспорт

Запросы можно экспортировать в формат HAR (HTTP Archive) или скопировать как cURL.
