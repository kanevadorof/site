Профилирование в Performance & Memory

Панели Performance и Memory позволяют выявлять «узкие места» рендеринга, просадки кадров (FPS) и утечки оперативной памяти.

Метрики Web Vitals (Core Web Vitals)
  • LCP (Largest Contentful Paint): Время отрисовки самого крупного видимого элемента.
  • INP (Interaction to Next Paint): Отклик интерфейса на действия пользователя.
  • CLS (Cumulative Layout Shift): Визуальная стабильность верстки.

Поиск утечек памяти в панели Memory

Инструмент Heap Snapshot делает снимок распределения памяти в куче JavaScript для обнаружения незакрытых обработчиков событий и отсоединенных DOM-узлов.

Оптимизация

Целевая частота кадров для плавного скролла и анимаций составляет 60 FPS (16.6 миллисекунд на кадр).
