Отладка кода и брейкпоинты в панели Sources

Панель Sources (Отладчик JavaScript)

Панель Sources предназначена для пошаговой отладки JavaScript-кода, установки точек останова (Breakpoints) и редактирования файлов скриптов.

Виды точек останова (Breakpoints)
  • Line-of-code Breakpoints: Остановка на конкретной строке кода.
  • Conditional Breakpoints: Срабатывание остановки только при выполнении логического условия.
  • DOM Breakpoints: Остановка при модификации выбранного узла DOM.
  • XHR/Fetch Breakpoints: Остановка при выполнении сетевого запроса к конкретному URL.

Карты исходного кода (Source Maps)

При использовании бандлеров (Webpack, Vite) и минифицированного кода Source Maps сопоставляют скомпилированный JS с исходными исходниками TypeScript/ES6.

Стек вызовов

Панель Call Stack показывает всю цепочку функций, приведших к текущей остановке.
