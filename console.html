Интерактивная консоль JavaScript (Console)

Панель Console

Консоль браузера служит для вывода системных сообщений, ошибок JavaScript, предупреждений и выполнения интерактивного кода в контексте текущей страницы.

Методы объекта console
  • console.log(data) — Базовый вывод информации.
  • console.warn(msg) — Вывод предупреждающего сообщения (желтый флаг).
  • console.error(err) — Вывод ошибки с трассировкой стека вызовов.
  • console.table(array) — Удобный вывод массива объектов в виде таблички.
  • console.time() / console.timeEnd() — Измерение точного времени выполнения кода.

Переменная $0

Специальное зарезервированное имя $0 в консоли ссылается на элемент, выделенный прямо сейчас на панели Elements.

Фильтрация

Вы можете фильтровать логи по уровню: Verbose, Info, Warnings, Errors.
