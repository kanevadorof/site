Работа с DOM и CSS в панели Elements

Панель Elements (Инспектор структуры)

Панель Elements позволяет просматривать HTML-дерево страницы, редактировать атрибуты, классы, текстовый контент и стили CSS прямо в реальном времени без перезагрузки страницы.

Основные функции панели Elements
  1. Изменение стилей (Styles): Добавление новых CSS-свойств, тест цветов, шрифтов и отступов.
  2. Вычисленные стили (Computed): Просмотр итоговых значений свойств с учетом каскада CSS.
  3. Блочная модель (Box Model): Визуальное представление margin, border, padding и content.
  4. Отладка Flexbox и Grid: Подсвечивание направляющих линий сеток и выравнивания.

Отладка псевдосостояний (:hover, :active, :focus)

Для проверки отображения кнопок и ссылок при наведении мыши включите принудительное состояние (Force State) через меню :hov в правой части панели Elements.

Быстрые советы

Двойной клик по любому тегу или атрибуту в DOM-дереве позволяет мгновенно отредактировать его значение.
